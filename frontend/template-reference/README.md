# Template reference

Unused TailAdmin demo code, kept for reference only. It is **not** part of the
build: it lives outside `src/` (so `tsc` and Vite never see it) and is ignored
by ESLint. Its imports point at `src/`-relative paths and will not resolve from
here -- copy a file back into `src/` (same relative path) to use it.

Contents: dashboard widgets (`components/ecommerce`), chart demos, the demo
tables/forms/UI-element pages, the calendar, the notification dropdown, the
legacy header, and the sidebar promo widget.
